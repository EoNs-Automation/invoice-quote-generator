# Invoice / Quote Generator

A simple tool for creating professional invoices and quotes.

## Features

- Create invoices or quotes
- Add multiple line items
- Automatic tax calculation
- Optional notes
- Download as a text file
- Available as both a Python script and a web tool

## Live Demo

[Try the web version here](https://invoice-quote-generator-164.netlify.app/)

## How to Use (Python)

1. Run the script
2. Choose Invoice or Quote
3. Enter business and client details
4. Add items (description, quantity, price)
5. Optionally add tax and notes
6. Save the document to a file

## Project Structure

- Python version of the generator
- Web version (HTML + JavaScript)
